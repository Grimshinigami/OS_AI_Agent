# An OS level AI Agent that can interact with your Windows system as well.

## Installation and Setup guide

Download the zip file and go to the directory of the project in terminal.

(Optional) Setup virtual python enviornment, Run the command `python -m venv env`

(Optional) Activate the virtual enviornment, Run the command `env\Scripts\activate.bat`

Run the command `pip install -r requirements.txt` 

Run the main python file `python main.py` 

The agent is now running in the terminal.

Say the Hey Vice keyword for invoking the Agent

The agent then listens to your prompt and returns the answer.

## Current Supported Functionality (Beta)

Currently the Agent can look at your screen and give answers related to it.

Perform simple interactions with the system such as launching chrome and performing a search.

Providing summarisation according to context.

Write code in your window.

Functionality may vary as project currently in Beta phase.
